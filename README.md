# TOPUS — инструменты

Статические страницы для GitHub Pages. Внешних зависимостей и серверной части нет:
каждый файл открывается самостоятельно, данные остаются в браузере (localStorage).

| Страница | Что делает |
|---|---|
| `index.html` | хаб: ссылки на все инструменты |
| `credit-holidays/index.html` | разбор кредитных каникул для МСП и самозанятых по 276-ФЗ (A4) |
| `credit-holidays/checker.html` | проверка права на каникулы + расчёт паузы и нового платежа |
| `claims/index.html` | генератор претензий и жалоб: 5 шаблонов |
| `kp/index.html` | конструктор коммерческого предложения (A4, сумма прописью, .doc) |
| `nalog/index.html` | генератор пояснений для налоговой: 12 типов требований, библиотека документов, организации |
| `zaim/index.html` | генератор договора займа между физлицами (A4, .doc) |
| `dv-anketa/index.html` | анкета DV: сбор данных, проверки, готовый блок для заполнения |
| `dv-pamyatka/index.html` | памятка участнику розыгрыша DV для печати A4 |

## Публикация

Pages отдаётся из ветки `main`, корень репозитория (`.nojekyll` отключает Jekyll).

## Важно

Калькулятор считает по учебной модели (месячная ставка = годовая / 12, аннуитетный платёж).
Генераторы создают черновики документов — проверяйте реквизиты, суммы и правовые формулировки
перед подписанием и отправкой. Материалы носят информационный характер.
