# TOPUS — банковские инструменты

Статические страницы для GitHub Pages. Внешних зависимостей и серверной части нет:
каждый файл открывается самостоятельно, данные остаются в браузере (localStorage).

| Страница | Что делает |
|---|---|
| `index.html` | хаб: ссылки на инструменты |
| `credit-holidays/index.html` | разбор кредитных каникул для МСП и самозанятых по 276-ФЗ (A4, 7 страниц) |
| `credit-holidays/checker.html` | проверка права на каникулы + расчёт стоимости паузы и нового платежа |
| `claims/index.html` | генератор претензий и жалоб: 5 шаблонов с подстановкой данных |

## Публикация

Pages отдаётся из ветки `main`, корень репозитория (`.nojekyll` отключает Jekyll).

## Важно

Калькулятор считает по учебной модели (месячная ставка = годовая / 12, аннуитетный платёж).
Шаблоны документов справочные: сроки и суммы (10 дней на ответ, 14 дней периода охлаждения,
30 дней до финуполномоченного, лимит 500 000 ₽) проверяйте на дату подачи — нормы меняются.
